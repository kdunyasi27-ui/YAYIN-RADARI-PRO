
# YAYIN RADARI PRO

TikTok canlı yayın güvenliği ve denetim paneli.

## Özellikler
- Kullanıcı adı ile hedef ekleme
- Yayın bağlantısı ile hedef ekleme
- Spam yorum analizi
- Şüpheli davranış incelemesi
- Denetim kayıtları
- JSON dışa aktarma
- Mobil uyumlu tasarım

## Kurulum

npm install
npm run dev

## Yayınlama

GitHub deposunu Vercel'e bağlayın.
Build Command: npm run build
Output Directory: dist

## Not
Bu sürüm manuel sağlanan verileri analiz eden prototiptir.
TikTok canlı yayın API bağlantısı içermez.
